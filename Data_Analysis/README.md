\# Data Analysis (Kisan Setu)

\- analysis\_notebook.ipynb: Data cleaning, graphs aur insights ka code.

\- graphs/: 4 graphs (monthly trend, crop average, onion by month, top states).



Data: Agmarknet mandi prices (Kaggle), 8,11,131 rows.

Insights: Tomato sabse mehngi, Potato sabse sasti. Onion November mein sabse mehnga aur June mein sabse sasta.
